# Portfolio Website

A modern, responsive personal portfolio website showcasing my projects, skills, and professional experience. Built with a fast and scalable frontend stack.

🔗 **Live Demo:** [https://your-live-site-url.com](https://your-live-site-url.com)

---

## 🛠 Tech Stack

- **React** – Component-based UI
- **TypeScript** – Type safety and maintainability
- **Tailwind CSS** – Utility-first styling
- **Vite** – Fast build tool and dev server
- **Lucide React** – Clean and customizable icons

---

## ✨ Features

- 🎨 **Responsive Design** – Optimized for mobile, tablet, and desktop
- 🚀 **High Performance** – Fast load times with Vite
- 💫 **Interactive UI** – Smooth animations and transitions
- 🧩 **Well-Structured Sections**
  - **About** – Introduction and background
  - **Skills** – Technical skillset
  - **Projects** – Selected work and case studies
  - **Experience** – Professional timeline
  - **Contact** – Social links and contact form

---

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/CodeNeuron58/My-Portfolio.git
```

### 2. Install dependencies

```bash
cd My-Portfolio
npm install
```

### 3. Start the development server

```bash
npm run dev
```
