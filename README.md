# Portfolio Website

My personal portfolio website showcasing my projects, skills, and experience. Built with modern web technologies for high performance and responsiveness.

## 🛠️ Built With

- **[React](https://reactjs.org/)** - UI Library
- **[TypeScript](https://www.typescriptlang.org/)** - Type Safety
- **[Tailwind CSS](https://tailwindcss.com/)** - Styling
- **[Vite](https://vitejs.dev/)** - Build Tool
- **[Lucide React](https://lucide.dev/)** - Icons

## ✨ Features

- 🎨 **Modern & Responsive Design**: Works seamlessly on all devices (Mobile, Tablet, Desktop).
- 🚀 **Fast Performance**: Optimized with Vite.
- 💫 **Interactive UI**: Smooth animations and transitions.
- 📱 **Sections**:
  - **About**: Introduction and professional background.
  - **Skills**: Technical proficiency overview.
  - **Projects**: Showcase of my work.
  - **Experience**: Professional timeline.
  - **Contact**: Functional contact form and social links.

## 📦 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/CodeNeuron58/My-Portfolio.git
   ```

2. **Install dependencies**
   ```bash
   cd My-Portfolio
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
